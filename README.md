# ФотоPDF

Веб-приложение на Python (FastAPI) для объединения изображений в PDF и сжатия PDF-файлов.

Исходная версия подготовлена для Render. PDF обрабатываются на сервере, временные файлы удаляются после запроса.

Перед публикацией в Render убедитесь, что настроены ограничения загрузок, HTTPS и защита от злоупотреблений.
